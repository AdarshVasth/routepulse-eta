# RoutePulse ETA

A local Python demo that estimates delivery time from distance, traffic, stops and rain. It uses a scikit-learn random forest trained on 1,600 synthetic trips generated by the project. No API key or live service is needed.

## Run it

Install Python 3.11 or newer. From this directory, create and activate a virtual environment.

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python eta.py predict --distance 12 --traffic moderate --stops 3 --rain
python eta.py evaluate
python -m unittest -v
```

On macOS or Linux, use `python3 -m venv .venv` and `source .venv/bin/activate` for the first two commands.

Traffic may be light, moderate or heavy. The simulated range is 1–25 km and 0–8 stops. Leave out `--rain` for dry conditions.

## How it works

1. A seeded generator samples inputs and simulates delivery times with Gaussian noise.
2. A seeded train/test split holds out 400 trips before model training.
3. The random forest predicts minutes. The evaluation compares its mean absolute error with a fixed distance-only heuristic.

On the bundled simulation, the forest scored 2.30 minutes MAE and the heuristic scored 9.84 minutes MAE. This measures performance on the same synthetic process used to generate training data. The model has no live traffic feed, GPS routing or validation against actual delivery records.

## Try this

Run the same trip with light and heavy traffic. Change the number of trees in `train()` and rerun evaluation to see how the error changes. Look at `sample_trips()` to understand why the simulated model expects traffic and distance to interact.

The synthetic examples can be reproduced by calling `sample_trips()` and may be reused or redistributed without restriction.
